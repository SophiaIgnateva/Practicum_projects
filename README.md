# Description of projects 

1) **Project BPMN to be for "Samokat".** dditional use cases have been identified for "Samokat" as a source of recipes for the app's users. This model demonstrates how the recipe feature can be used to attract and retain Samokat's customers, as well as to encourage users to place new orders via the app. *Instrument: draw.io*
2) **User Story Map.** In total, three types of users were considered, and user activities and tasks were written. The main first iteration included solutions to current problems, such as collecting customer feedback, transferring customer support communication to the bank's app, and creating scripts to answer popular customer questions. *Instrument: Miro*
3) **Low-fi prototypes.** Low-fi prototypes have been created for the client in the bank's app after the updates. The first screen is the main page of the bank's app. The second screen is the chat screen. The third screen is the support chat screen. If there are clickable links to frequently asked questions. After the support response, a support evaluation window will appear. *Instrument: Miro*
4) **Functional requirements describing the use cases.** The interaction system between the laundry service and linen hotels, as well as the operation of logistics services, has been studied. A requirements document for the solution has been prepared, describing all use cases. *Instrument: draw.io*
5) **Test Program and Procedure.** The document contains a list of checks that must be successfully completed for the new product to be accepted by the customer for industrial operation. Functional and non‑functional requirements are described.
6) **Technical Specification Document.** The interaction system between the laundry service and linen hotels, as well as the operations of the logistics services (including the activities of the logistics manager and the driver), has been studied. Two departments have been examined: the Linen Department and the Logistics Management Department. The current processes have been investigated, including inventory, linen collection, linen delivery, and planning. Interviews were conducted with the hotel owner, the linen department supervisor, and the logistics manager. Both the “as‑is” and “to‑be” processes (developed by the hotel owner) were reviewed, along with the meeting minutes.
7) **Survey Report Document.** The shortcomings of the “as‑is” processes have been identified, and the necessary changes have been justified and described. The expected changes in the “to‑be” process have also been outlined.
