# Description of projects 
## All projects have been done during course Yandex Practicum and hackathon
1) **Project BPMN to be for "Samokat".** dditional use cases have been identified for "Samokat" as a source of recipes for the app's users. This model demonstrates how the recipe feature can be used to attract and retain Samokat's customers, as well as to encourage users to place new orders via the app. *Instrument: draw.io*
2) **User Story Map.** In total, three types of users were considered, and user activities and tasks were written. The main first iteration included solutions to current problems, such as collecting customer feedback, transferring customer support communication to the bank's app, and creating scripts to answer popular customer questions.
